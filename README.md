A modern, full-stack **College Enterprise Resource Planning (ERP)** dashboard designed to streamline academic operations for students, faculty, and administrators.

✨ Features
- 🔐 **Role-based Authentication:** Separate views and permissions for Students, Faculty, and Admin.
- 📊 **Interactive Dashboard:** View real-time statistics including overall attendance, active courses, and upcoming assignment deadlines.
- ⚡ **Fast & Responsive UI:** Built with Vite, React, and styled using Tailwind CSS for seamless responsiveness.
- 🚀 **RESTful API Backend:** Modular Node.js and Express backend handling authentication and routing securely.

🛠️ Tech Stack
**Frontend**
**Framework:** React.js (Vite)
**Styling:** Tailwind CSS
**HTTP Client:** Axios
**Icons:** Lucide React / Emoji Utilities

### **Backend**
**Runtime:** Node.js
**Framework:** Express.js
**Auth & Security:** JSON Web Token (JWT) & Bcryptjs
**Database Connection:** MongoDB / Mongoose
