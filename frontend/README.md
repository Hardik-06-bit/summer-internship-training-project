# 🎓 EduManage ERP — Enterprise College Management Portal

EduManage ERP is a full-stack academic management ecosystem engineered to streamline institutional workflows, optimize student data administration, and provide real-time performance analytics.

---

## 🚀 Live Services
- **Frontend Live Deployment (Vercel):** [https://summer-internship-training-project-pink.vercel.app/](https://summer-internship-training-project-pink.vercel.app/)
- **Backend REST API Service (Render):** [https://summer-internship-training-project.onrender.com](https://summer-internship-training-project.onrender.com)

---

## ✨ System Features
- **Cryptographic Authentication Flow:** Secure Sign-Up and Sign-In architecture using stateless JWT tokens and ciphered MongoDB persistence.
- **Dynamic Analytics Dashboard:** Interactive single-page interface rendering synchronous updates for attendance thresholds, core curricular modules, and impending scholastic deliverables.
- **Modern Responsive UI/UX:** Built with a dark enterprise glassmorphism aesthetic using React, Tailwind CSS, and Lucide React icons.
- **Automated Cloud Architecture:** Decoupled continuous deployment pipeline featuring Vercel for frontend hosting and Render for backend services.

---

## 🛠️ Technology Stack

| Layer | Technology |
| :--- | :--- |
| **Frontend** | React.js, Tailwind CSS, Lucide React, Axios |
| **Backend** | Node.js, Express.js, JSON Web Tokens (JWT) |
| **Database** | MongoDB Atlas (Mongoose ODM) |
| **Deployment** | Vercel (Client), Render (Server) |
